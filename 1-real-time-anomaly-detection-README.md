# Real-Time Anomaly Detection using Raspberry Pi

**Final Year Project | Machine Learning**
*Apr 2025 - Apr 2026*

## 📋 Overview
A machine learning-based system designed to detect abnormal events in surveillance video streams in real time. The project combines computer vision and embedded hardware (Raspberry Pi) to build a lightweight, deployable anomaly detection solution suitable for security and monitoring applications.

## 🎯 Objective
To build a system capable of automatically identifying unusual or suspicious activity in video footage without requiring constant human monitoring, reducing response time to potential security threats.

## ⚙️ How It Works
1. Video streams are captured and processed frame-by-frame.
2. Machine learning models analyze patterns of "normal" behavior in the footage.
3. Deviations from these learned patterns are flagged as anomalies.
4. Alerts/logs are generated when abnormal events are detected.

## 🛠️ Tech Stack
- **Hardware:** Raspberry Pi
- **Language:** Python
- **Domain:** Machine Learning, Computer Vision
- **Tools:** Google Colab (model training/testing)

## 🚀 Features
- Real-time video stream processing
- Anomaly/event detection using ML models
- Lightweight deployment on edge hardware (Raspberry Pi)
